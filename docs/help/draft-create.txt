Usage of draft create:
  -body string
    	body
  -body-file string
    	body from file or -
  -stdin
    	read body from stdin
  -subject string
    	subject
  -tag value
    	tag (repeat)
  -to value
    	recipient (repeat)

Requires at least one --to and exactly one body source: --body, --body-file or --stdin.
Example: protonmailcli --dry-run draft create --to user@example.invalid --body Example
