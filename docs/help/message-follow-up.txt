Usage of message follow-up:
  -body string
    	body
  -body-file string
    	body from file or -
  -idempotency-key string
    	idempotency key
  -message-id string
    	message id
  -stdin
    	read body from stdin
  -subject string
    	subject override
  -to value
    	recipient (repeat)

Requires --message-id and one body source; creates a follow-up draft. Recipients are derived from the original message unless --to overrides them.
Example: protonmailcli --dry-run message follow-up --message-id 123 --to user@example.invalid --body Example
